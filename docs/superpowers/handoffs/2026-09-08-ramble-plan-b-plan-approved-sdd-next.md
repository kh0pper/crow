## ⚠ Incident + lesson (memory `crow-review-mirror-shares-worktree-gitdir`)
`cp -a` of a git WORKTREE copies its `.git` pointer file, so a review mirror shares the real branch. Round 2's reviewer committed six task commits onto `feat/profile-avatar-sharing`; they were reset away (nothing pushed) and the first scoped check, which had verified those stale commits, was voided and redone in an isolated mirror. Build mirrors with `rsync -a --exclude .git --exclude node_modules … && git init`, never `cp -a`. Before trusting any gate, check `git log` in the real worktree.
