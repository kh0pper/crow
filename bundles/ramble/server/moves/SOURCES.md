# Moves library — source register

One row per source the moves library may cite. A row stays **UNVERIFIED**
until someone has opened the host page, confirmed the license still says what
this table says, and filled in the URL-checked and date-checked columns.

**An UNVERIFIED source may not be cited by any entry.** `validateEntry`
requires a non-empty `sources` list with a license per source; the review pass
that sets `"reviewed": true` (the only gate to serving) is where this table is
checked against the entry's citations.

Started from spec §7 and the F19 notes (private engineering notes). URLs are
deliberately empty until verified — record the exact host page checked, not a
search result.
